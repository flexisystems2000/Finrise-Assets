FINRISE ASSET - SUPABASE FRONTEND MIGRATION

This ZIP contains the complete frontend files updated for the current Supabase-backed architecture.

Source of truth:
- Supabase Auth for authentication/session
- public.profiles for user profile
- public.wallets for balances
- public.deposits for deposit requests
- public.withdrawals for withdrawal requests
- public.ledger_entries for transaction history
- public.referrals / public.referral_rewards for referrals
- public.investment_plans / public.investments for investments

Important current backend state:
- 0 active investment plans currently exist in Supabase.
- 0 admin_roles currently exist.
- Trading/order functionality is intentionally not fabricated because the backend has no trading/order table or RPC.
- Investment buttons therefore require real active rows in investment_plans before they can create investments.
- The wallet currency is NGN, so financial dashboard/deposit/withdrawal displays use NGN.

Do not put a Supabase service-role key in frontend files. The frontend must use only the public/publishable key.
